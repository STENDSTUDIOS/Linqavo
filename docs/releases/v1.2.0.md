## Windows now installs from Setup

[Download Windows Setup (x64)](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.2.0/Linqavo-Setup-x64-1.2.0.exe) · [Download Android (ARM64)](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.2.0/Linqavo-1.2.0-android-arm64-debug.apk) · [SHA-256 checksums](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.2.0/SHA256SUMS.txt)

- **Windows 10/11 x64.** Exit the 1.1.0 portable copy and run Setup. Launch Linqavo from Start and manage it under Installed apps. Setup includes the helper, Wintun and the runtime. Windows may show an unknown-publisher warning because Setup is unsigned.
- **Android ARM64.** Open the APK and confirm the update. It includes both Share Internet and Connect to Internet. The application ID and development signing certificate match the published 1.1.0 APK.
- **Future updates.** Starting with 1.2.0, the foreground app checks the latest stable release on STENDSTUDIOS/Linqavo. When an update is available, **Update** opens the matching download in your browser. Open the downloaded file to install it. You can also check from Settings. Version 1.1.0 needs this first upgrade manually.

The Android JVM suite passed 192 tests. The Windows suite passed 255 tests. Android lint reported zero errors and 25 warnings. Physical-device upgrade and tunnel acceptance for 1.2.0 remain pending.
