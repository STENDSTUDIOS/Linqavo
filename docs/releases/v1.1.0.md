## Your phone’s internet, on more devices

Linqavo 1.1.0 brings Android-to-Android sharing, a Windows dashboard and compact status window, and remembered trusted devices.

### Download

| Platform | Package |
| --- | --- |
| Android 8+ · ARM64 | [Download Android APK](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.1.0/Linqavo-1.1.0-android-arm64-debug.apk) |
| Windows 10 / 11 · x64 | [Download Windows ZIP](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.1.0/Linqavo-1.1.0-windows-x64.zip) |
| Verify your download | [SHA256SUMS.txt](https://github.com/STENDSTUDIOS/Linqavo/releases/download/v1.1.0/SHA256SUMS.txt) |

The Android APK includes **Share Internet** and **Connect to Internet**. Extract the complete Windows ZIP and open **Linqavo.exe**.

### Included

- Up to three independently authorized clients, including mixed Android and Windows clients.
- Trusted devices that reconnect after sharing restarts.
- Per-device disable, enable, and revocation.
- Pinned TLS enrollment, client-owned keys, and authenticated presence.
- Navy and blue visual identity, separate desktop Settings, and a compact status window.

### Build and validation notes

Android uses a development signing key. The Windows application is unsigned. Updates are manual.

Emulator testing verified trusted-client reconnection after restarting sharing. Physical acceptance of this release, three simultaneous clients, crash-safe Windows protection, and DNS/IPv6 leak verification remain pending.
